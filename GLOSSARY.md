# Skills Hub

The hub brings together skills for installation in projects or for global use.

## Language

**Skills hub**:
The collection of available skills managed through this repository.

**Repository source**:
A repository explicitly listed as a provider of selected skills for the hub.

**Third-party skill**:
A skill maintained by someone other than the repository owner.

**Plugin**:
A package installed as a whole through an agent's plugin installer.
It can contain skills, agents, hooks, and servers.

**Catalog entry**:
A selectable skill or plugin offered by the hub.

**Project installation**:
An installation of selected skills for use in one project.

**Global installation**:
An installation of selected skills for use across projects.
